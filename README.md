# thecofwo.org

Website and admin for **The Chariot of Fire World Outreach (COFWO)**.

- **Website:** Next.js 16, hosted on Vercel
- **Admin (`/admin`):** Payload CMS 3, running inside the same app
- **Database:** Postgres on Neon
- **Photos:** Neon Object Storage (S3-compatible bucket)
- **Email (optional):** Resend, for form notifications

The previous static site is kept in [`legacy/`](legacy/) for reference. The seed script imports its content.

## What staff can manage in the admin

| Area | Where in the admin |
|---|---|
| Homepage, About, Give and Contact page text and photos | Website pages |
| Extra pages (privacy policy, etc.) | Website pages → Other pages |
| Blog posts (drafts, publishing, categories) | Blog |
| Sermons (YouTube/Facebook/Vimeo), events, testimonies, gallery albums | Ministry |
| Contact messages and newsletter subscribers (with CSV export) | Inbox |
| Service times, address, livestream links, social links, mission and vision, announcement bar, SEO defaults, footer | Settings → Site settings |
| Top menu and footer links | Settings → Menus |
| Who can sign in (admins and editors) | Admin → Team members |

A **Before launch** checklist on the dashboard shows which ministry details are still missing. Saving in the admin updates the live site straight away. Editors can **Preview** drafts on the real site before publishing.

## Run it locally

Needs Node 22 or newer.

```bash
npm install
cp .env.example .env        # then set PAYLOAD_SECRET
npm run db                  # local Postgres; leave it running in its own terminal
npm run seed                # imports the old site's content (first time only)
npm run dev                 # http://localhost:3000, admin at /admin
```

The first visit to `/admin` asks you to create the first admin account.

| Command | What it does |
|---|---|
| `npm run dev` | Development server |
| `npm run db` | Local Postgres on port 54341 (data in `.localdb/`) |
| `npm run seed` | Imports content from `legacy/` into an empty site |
| `npm run seed:reset` | Deletes site content (not messages, subscribers or users) and imports again |
| `npm run migrate:create -- <name>` | Creates a database migration after changing collections or fields |
| `npm run generate:types` | Updates `src/payload-types.ts` after changing collections or fields |
| `npm run build` | Production build |

## Project layout

```
src/
  app/(frontend)/   public website pages
  app/(payload)/    admin and API (generated by Payload)
  collections/      admin content types (posts, events, messages, ...)
  globals/          single-page settings (homepage, site settings, menus, ...)
  components/       website components
  migrations/       database migrations (run automatically on Vercel)
  seed/             content import from legacy/
  proxy.ts          "410 Gone" for the old WordPress demo pages
legacy/             previous static site and its docs
docs/               deployment and admin guides
```
